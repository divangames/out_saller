# OUTMAX SALE

Адаптивный прототип интернет-магазина OUTMAX с накопительной скидкой до 50%. Проект работает как статический сайт без сборки и опубликован через GitHub Pages.

[Открыть сайт](https://divangames.github.io/out_saller/)

## Возможности

- каталог кроссовок, одежды и аксессуаров с фильтрами;
- поиск по названию и полному или частичному артикулу на компьютере и телефоне;
- импорт полного каталога, цен, фотографий, характеристик и размеров из YML;
- индивидуальные описания, характеристики и фотогалереи товаров;
- карусель фотографий со стрелками, прокручиваемыми миниатюрами и увеличением по клику;
- мужские и женские таблицы размеров;
- отображение длины стопы и остатка выбранного размера;
- корзина с автоматическим расчётом скидки;
- оформление заявки с проверкой формы и выбором ПВЗ;
- локальные подсказки по 1102 городам России;
- адаптивный интерфейс для компьютеров и мобильных устройств;
- сохранение корзины в `localStorage`;
- hash-маршрутизация, совместимая с GitHub Pages.

## Локальный запуск

На Windows запустите:

```text
START.bat
```

и выберите пункт `1. Запуск`.

Либо запустите любой статический HTTP-сервер из корня проекта:

```powershell
python -m http.server 4173
```

После этого откройте [http://127.0.0.1:4173/#home](http://127.0.0.1:4173/#home).

Открывать `index.html` напрямую через `file://` не рекомендуется: браузер ограничивает загрузку локальных файлов и часть функций может не работать.

## Обновление данных

Полный каталог из `https://outmaxshop.com/yml/all.yml` (Python 3, без зависимостей):

```powershell
python scripts/sync-catalog.py
```

Из уже скачанной выгрузки:

```powershell
python scripts/sync-catalog.py --feed artifacts/catalog-source.yml
```

Парсер проверяет данные и атомарно обновляет `product-catalog.js`; при ошибке прежний снимок сохраняется. Недоступные товары исключаются. Цены, фото, характеристики и размеры берутся из выгрузки, количества по размерам не выдумываются. У двух товаров текущей выгрузки размеры отсутствуют: купить их без выбора размера нельзя. Товары прежнего каталога, отсутствующие в этом источнике (включая аксессуары), сохраняются без демонстрационных дублей. Загружать YML из браузера не требуется, поэтому поиск работает и на GitHub Pages без CORS-прокси.

Снимок от 16.10.2026 содержит 8 167 товаров из YML. После обновления перезагрузите страницу. Для публикации обновите снимок в каждом репозитории.

Поиск раскрывается по иконке лупы в главном меню: перед корзиной сверху на компьютере и сразу после «Одежды» в нижнем меню на телефоне. При вводе отображается до пяти совпадений с фото, названием, артикулом и ценой с учётом текущей накопительной скидки корзины. Если совпадений больше пяти, кнопка «Показать весь список» с общим количеством открывает полные результаты. Нажатие на подсказку открывает карточку товара; Enter или кнопка «Найти» открывают всю выдачу.

Полная выдача доступна по адресу `#search?q=...` на локальном сервере и GitHub Pages. На другом хостинге используется `/search?q=...`, как и существующая маршрутизация проекта. Регистр, лишние пробелы и различие «е/ё» не влияют на результат. Поддерживаются стрелки вверх/вниз для перехода по подсказкам, Escape и клик вне панели для закрытия, очистка ввода, пустое состояние, подгрузка результатов и возврат из карточки. Панель не сдвигает содержимое страницы; на небольшом экране список прокручивается, а кнопка полного списка остаётся доступной.

Дополнительные старые снимки (применяются только к прежним товарам, отсутствующим в новом YML):

Галереи из `https://outmaxshop.com/yml/all.yml`:

```powershell
pwsh -File scripts/sync-product-photos.ps1
```

Остатки из `https://outmaxshop.ru/yml/all_yandex.yml`:

```powershell
pwsh -File scripts/sync-product-stock.ps1
```

Описания и расширенные данные из заранее скачанной выгрузки:

```powershell
pwsh -File scripts/sync-product-details.ps1 -FeedPath artifacts/all_yandex.yml
```

Скрипты обновляют статические снимки данных. Перед публикацией рекомендуется повторно получить актуальные остатки.

## Публикация

Push в ветку `main` автоматически запускает workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) и публикует только файлы сайта на GitHub Pages: HTML, CSS, JavaScript, images и assets. Документация и скрипты разработки в публикацию не входят.

На Windows команды для коммита, push и ручного запуска публикации также доступны через `START.bat`.

## Важные ограничения

- Это статический прототип: актуальность цен и остатков зависит от последнего обновления YML-снимков.
- Расчёт доставки и перечень ПВЗ пока заданы демонстрационными данными и не подключены к API СДЭК.
- Данные Telegram-бота хранятся только локально в `TG BOT.txt`; файл исключён из Git. Для production токен необходимо перенести на сервер и не выдавать браузеру.
- Пользовательский ввод города не отправляется внешним сервисам: подсказки работают по локальному справочнику.

## Фотографии товара

Основное фото переключается стрелками ‹ ›, кликом по миниатюре, клавишами ←/→ при фокусе в галерее или горизонтальным свайпом на телефоне. Лента миниатюр имеет собственные стрелки прокрутки; на её краях недоступная стрелка отключается. Выбранное фото и миниатюра синхронизированы, выбор размера и положение страницы сохраняются.

Клик по фото открывает большой просмотр с каруселью и миниатюрами. Кнопка лупы или повторный клик по изображению включает двукратное увеличение с прокруткой. Смена фото сбрасывает дополнительное увеличение. Закрытие: крестик, Escape или клик по затемнению; фокус возвращается к исходному фото. Для единственной фотографии стрелки и миниатюры не отображаются.
